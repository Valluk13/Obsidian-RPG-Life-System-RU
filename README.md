# 🗡️ Obsidian RPG Life Management System
Превратите свою жизнь, привычки и обучение в полноценную RPG-игру прямо внутри вашего хранилища Obsidian.

---
## 1. Архитектура и концепция системы

Система спроектирована как полноценное decoupled-приложение (с разделением логики и представления) внутри Obsidian:
* **Вычислительное ядро (Backend):** Автономный классовый движок `RPG_Engine.js`, написанный на чистом JavaScript. Работает через плагин `CustomJS`. Ядро полностью отказалось от ресурсоемкого текстового парсинга и производит все вычисления на лету через обращение к API-кэшу метаданных Obsidian (YAML Frontmatter). Время отклика интерфейсов составляет менее 4 мс.
* **Интерфейсный слой (Frontend):** Динамические интерактивные виджеты, построенные на `DataviewJS` и асинхронном HTML/CSS-рендеринге, реагирующие на внутренние системные события (`CustomEvent`).

## 2. Глобальный цикл активности (Core Loop)

Любое действие в реальном мире фиксируется пользователем через интерфейсы Obsidian и мгновенно конвертируется в числовые параметры персонажа: Опыт (XP), Золото (GP) и Здоровье (HP).

### Таблица конвертации видов деятельности

| Деятельность в реальном мире | Системный статус | Награда / Штраф | Психологическая роль |
| :--- | :--- | :--- | :--- |
| Глубокая работа / Учеба | `🔴 Focus` | +1 XP и +1 GP за 1 минуту | Мотивация к удержанию концентрации |
| Бытовые задачи / Рутина | `🪵 Routine` | +0.5 XP и +0.5 GP за 1 минуту | Закрытие базовых обязательств |
| Осознанный отдых / Сон | `⚪ Rest` | 0 XP / 0 GP (Трекинг баланса) | Защита от выгорания, легализация отдыха |
| Прокрастинация / Слив времени | `⚠️ Waste` | **-1 GP** за 1 минуту | Прямой экономический убыток за лень |
| Написание атомарных заметок | Создание файла в ZK | +10 XP за одну концепт-карту | Развитие Второго Мозга (Zettelkasten) |

## 3. Детальный разбор игровых механик

### Механика бесшовного переключения (Link Start)
Пульт времени в ежедневной заметке считывает Unix-время завершения предыдущей сессии из текстового лога. При активации чекбокса `🔗 Начать встык` временем старта нового таймера автоматически назначается время окончания предыдущего. Это исключает "трение" и потерю минут при мгновенном переключении между разнородными задачами.

### Боевая система квестов
Задачи в списке дел выступают в роли противников. Награда или штраф жестко привязаны к указанной сложности во фронтматтере или инлайн-поле задачи:

* **Легкий квест (`easy`):** +20 XP, +25 GP. Провал: -5 HP.
* **Средний квест (`medium`):** +50 XP, +50 GP. Провал: -15 HP.
* **Сложный квест (`hard`):** +100 XP, +100 GP. Провал: -30 HP.
* **Микро-задачи (без тега):** Любой стандартный чекбокс Obsidian автоматически расценивается как микро-поручение и приносит фиксированные +5 XP и +5 GP.
* **Частичное выполнение:** Чекбокс со статусом `[/]` начисляет ровно 50% от базовой награды квеста. Провал со статусом `[-]` наносит урон по HP.

### Математика уровней и рангов
Прогресс персонажа линеен. Для повышения уровня требуется ровно 1000 очков опыта (XP). 

Расчет текущего уровня:
$$Level = \lfloor \frac{\text{Total XP}}{1000} \rfloor + 1$$

Остаток опыта для прогресс-бара:
$$\text{XP Current} = \text{Total XP} \pmod{1000}$$

В зависимости от уровня, персонажу присваиваются системные титулы: от `🔮 Novice Adept` (1–9 уровень) до `🌌 Supreme Database Sage` (100+ уровень).

### Механика выживания (HP) и состояние Травмы
Максимальный запас энергии составляет 100 HP. Здоровье динамически пересчитывается Ядром на основе баланса штрафов и исцеления:
* **Штраф за пассивность:** Если за прошедшие сутки время в режиме `🔴 Focus` равно 0, персонаж получает урон -10 HP.
* **Исцеление за дисциплину:** Более 60 минут Фокуса за сутки при отсутствии проваленных квестов возвращают персонажу +10 HP.
* **Состояние Травмы (Debuff):** При падении HP до 0 или ниже, персонаж получает критическое ранение. **Весь заработок золота режется ровно на 50%**. Для снятия дебаффа необходимо приобрести и применить Зелье Лечения в Лавке.

### Экономика и Кредитный лимит
GP (Gold Points) — инструмент легализации твоего отдыха. Выполняя задачи, ты зарабатываешь капитал, на который в Магазине покупаешь право на развлечения (например, 1 час видеоигр стоит 220 GP).
* **Кредитный лимит:** Система позволяет совершать покупки в минус, переводя Лавку в режим `В кредит`. Однако при достижении жесткого лимита в **-500 GP** Лавка полностью блокируется до тех пор, пока долг не будет отработан реальной деятельностью.

### Доска Долгов (Board of Debts)
Все незакрытые квесты за прошлые дни текущего месяца не исчезают. Виджет на главной странице собирает их, сортирует хронологически (от старых к новым) и выводит единым списком. Дог висит на панели и мозолит глаза до тех пор, пока задача не будет выполнена, либо принудительно отменена со статусом провала `[-]` (с получением соответствующего урона по HP).

## 4. Спецификация YAML-свойств

Для корректной работы движка и плагина Dataview, метаданные ключевых файлов должны строго соответствовать следующим структурам.

### Ежедневная заметка (`05_Journal/YYYY-MM-DD.md`)
```yaml
---
timer_state: null       # Строка текущего режима (Focus/Routine/Rest/Waste)
timer_start: null       # Время старта в ISO формате
timer_elapsed: 0        # Накопленное время паузы в миллисекундах
timer_tags: ""          # Введенные теги сессии
last_timer_end: null    # Время Unix последнего стопа для функции "Встык"
focus_mins: 0           # Агрегированные минуты Фокуса за день
routine_mins: 0         # Агрегированные минуты Рутины за день
rest_mins: 0            # Агрегированные минуты Отдыха за день
waste_mins: 0           # Агрегированные минуты Слива за день
daily_xp: 0             # XP за тайм-трекинг
daily_gold: 0           # GP за тайм-трекинг
hp_lost: 0              # Ручной штраф к здоровью
tags_stat: {}           # Поминутная статистика тегов за день (генерируется авто)
---
```
Карточка Профиля (01_Dashboard/00_Profile.md)
```YAML
---
gold_spent: 0              # Общая сумма трат в магазине
bonus_xp: 0                # Сумма опыта, полученная за достижения
bonus_gold: 0              # Сумма золота за достижения
total_potions_consumed: 0  # Общее число выпитых зелий за всё время
potions_history: {}        # Карта выпитых зелий по датам { YYYY-MM-DD: 1 }
inventory:                 # Текущие остатки купленных предметов
  potion: 0
  walk: 0
  tea: 0
  youtube: 0
  games: 0
  social: 0
  dayoff: 0
archive_cutoff: "2000-01-01" # Дата-фильтр для Доски Долгов
---
```

## 5. Быстрый старт для пользователя
1. Скачайте архив репозитория и распакуйте его на локальный диск.
2. Откройте Obsidian, нажмите Открыть папку как хранилище (Open folder as vault) и выберите распакованную директорию.
3. Перейдите в Настройки Obsidian -> Сторонние плагины и убедитесь, что включены: Dataview, CustomJS, Templater.
4. В настройках Dataview обязательно включите опции: Enable JavaScript Queries и Enable Inline JavaScript Queries.
5. Откройте файл 01_Dashboard/Homepage.md. Система готова к работе.
